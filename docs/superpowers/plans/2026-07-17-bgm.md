# 배경 음악(BGM) 구현 계획

> **에이전트 작업자:** 태스크 단위로 구현. 순수 로직은 TDD(실패 테스트 먼저), build.rs DSP는 빌드시 인라인 assert로 불변식 검증. 실제 음악 퀄리티는 사용자 청취로 확인.

**목표:** 절차적 칩튠 7곡(타이틀 1 + 테마 6) + 음소거 토글(M키/메뉴, 지속). 스펙: `docs/superpowers/specs/2026-07-17-bgm-design.md`.

**아키텍처:** build.rs가 다성 칩튠 시퀀서로 7 루프 WAV 생성 → fx/music.rs가 상태/테마에 맞춰 재생·교체 → MusicEnabled(지속)가 M키·메뉴로 토글.

**기술:** Bevy 0.19 `bevy_audio`(AudioPlayer/PlaybackSettings::LOOP), bevy-persistent, build.rs 절차 생성(16bit PCM WAV, 22050Hz 모노).

## 전역 제약

- 음원 100% 절차 생성(build.rs), 외부 바이너리 없음. 출력 `assets/music/*.wav`, 22050Hz 모노.
- 지속: `MusicEnabled`를 bevy-persistent로. 경로는 `load_high_score`의 `#[cfg]` 분기 재사용(네이티브 config_dir / wasm `local/...`). 빌드시 삽입.
- 음소거는 **BGM만**. SFX·게임 로직·기존 테스트 불변.
- 온디맨드 로드(현재 트랙만). M은 미사용 키.

### Task 1: build.rs 음악 시퀀서 + 타이틀 트랙

**Files:** Modify `build.rs`

**Interfaces (Produces):** `assets/music/title.wav` 생성. build.rs 내부 함수 `note_hz`, `pulse`, `triangle`, `render_voice`, `mix_voices`, `write_music_wav`, `Voice`/`Note` 표현.

**설계:**
- `const A4: f32 = 440.0; fn note_hz(semi: i32) -> f32 { A4 * 2f32.powf(semi as f32 / 12.0) }` — 반음 오프셋(A4=0 기준 아님; 편의상 semi=0→A4). 스케일은 반음 오프셋 배열.
- 파형: `fn pulse(phase: f32, duty: f32) -> f32 { if phase.fract() < duty { 1.0 } else { -1.0 } }`, `fn triangle(phase: f32) -> f32 { (2.0 * (phase.fract() - 0.5).abs()) * 2.0 - 1.0 }`.
- 노트: `struct Note { semi: i32, beats: f32 }`(semi = i32::MIN 이면 쉼표). 보이스 = `Vec<Note>` + 파형종류 + 옥타브 오프셋 + amp.
- `render_voice(notes, bpm, wave, amp) -> Vec<f32>`: 각 노트를 `beats * 60/bpm`초 동안 렌더, 노트별 엔벨로프(어택 5ms 선형↑, 이후 선형↓ 릴리스로 노트 끝 직전 0). 파형 위상은 `hz * t` 누적.
- `mix_voices(voices: &[Vec<f32>]) -> Vec<i16>`: 최장 길이에 합산 → 최대절댓값으로 정규화(0.9배 헤드룸) → i16.
- `write_music_wav(dir, name, samples)`: 기존 `write_wav` 재사용(모노 16bit).
- **타이틀 트랙:** 장조 스케일, BPM 100, [베이스 삼각파 루트 + 아르페지오 펄스(성긴) + 리드(선택)]로 8~16마디. 실제 노트 배열은 구현자가 작곡(스펙 무드표: "은은한 어트랙트").

**불변식 assert(빌드시):**
- 생성 샘플 길이 == 정수 마디(= round(bars * beats_per_bar * beat_secs * SR))인지 `assert_eq!`.
- 루프 이음새: `samples[0].abs()` 와 `samples[last].abs()` 가 임계값(예 i16 0.02*MAX) 이하 → 클릭 없음 `assert!`.

- [ ] **Step 1:** `build.rs`에 `note_hz`/`pulse`/`triangle`/`Note`/`render_voice`/`mix_voices` 추가(SFX 코드 유지).
- [ ] **Step 2:** 타이틀 노트 패턴 작성 + `assets/music/` 디렉터리 생성 + `write_music_wav(dir, "title.wav", ...)`.
- [ ] **Step 3:** 루프 이음새·길이 불변식 `assert` 삽입.
- [ ] **Step 4:** `cargo build` — 재생성 확인, `assets/music/title.wav` 존재·크기 정상(수백 KB). `.gitignore`에 생성물 포함 여부 확인(기존 assets/sounds 취급과 동일하게).
- [ ] **Step 5:** 커밋.

**청취 체크포인트:** `cargo run` → 타이틀에서 음악이 나오는가?(이 태스크 후 사용자 확인 — 단, 재생 배선은 Task 3. 여기선 파일 생성만. 청취는 Task 3 이후.)

### Task 3: fx/music.rs 재생 코어

**Files:** Create `src/fx/music.rs`; Modify `src/fx.rs`(mod music), `src/main.rs`(MusicPlugin 등록)

**Interfaces (Produces):** `MusicPlugin`, `enum Track`, `Track::for_theme(ThemeId) -> Track`, `desired_track(&GameState, &Progression) -> Track`, `CurrentMusic` 리소스.

**설계:**
- `enum Track { Title, Belt, Fleet, Flare, Ice, Storm, Void }` + `fn file(self) -> &'static str`("music/xxx.wav").
- `fn for_theme(t: ThemeId) -> Track` — 6테마 매핑.
- `fn desired_track(state: &GameState, prog: &Progression) -> Track` — Title→Title; 그 외→for_theme(prog.current_theme()).
- `#[derive(Resource, Default)] struct CurrentMusic { track: Option<Track>, entity: Option<Entity> }`.
- `sync_music(commands, asset_server, state, prog, mut current)`: `desired = desired_track(...)`. `if current.track != Some(desired)`: 기존 entity despawn → `AudioPlayer(load(desired.file()))` + `PlaybackSettings::LOOP` 스폰 → current 갱신. (음소거는 Task 4에서 추가.)
- `MusicPlugin`: `init_resource::<CurrentMusic>()` + `add_systems(Update, sync_music)`.
- main.rs: `.add_plugins(fx::music::MusicPlugin)`.

**Interfaces (Produces):** `MusicEnabled(pub bool)` 지속 리소스, `toggle_music_key` 시스템. **Consumes:** Task 3 `sync_music`.

**설계:**
- `#[derive(Resource, Serialize, Deserialize)] struct MusicEnabled(pub bool)` 기본 true. `Persistent<MusicEnabled>`, 경로 `#[cfg]` 분기(load_high_score 패턴). main.rs 빌드시 `.insert_resource(load_music_enabled())`.
